# 보안/개인정보 점검 요약

## 1. 점검 일자

2026-06-19

## 2. 점검 범위

- `src/app`
- `src/components`
- `src/domain`
- `src/lib`
- `src/data`
- `docs/harness`
- `docs/output`
- `README.md`
- `package.json`

## 3. 점검 결과 요약

- 로그인, DB 저장, 서버 업로드, 결제 기능이 없다.
- 개인정보 입력 필드가 없다.
- localStorage는 관심종목, 알림 규칙, 포트폴리오 데이터 저장에만 사용한다.
- memo는 React text node로 렌더링되며 HTML로 직접 삽입하지 않는다.
- `dangerouslySetInnerHTML` 사용은 발견되지 않았다.
- 실제 광고, GA4/GTM, 제휴 스크립트 삽입은 발견되지 않았다.
- API KEY 하드코딩은 발견되지 않았다.

## 4. 발견된 문제

- 치명적인 보안/개인정보 문제는 발견하지 못했다.
- 배포 전 실제 도메인, 환경변수, 외부 스크립트 미삽입 상태는 사람이 다시 확인해야 한다.

## 5. 수정한 항목

- 보안/개인정보 체크리스트 문서 추가
- localStorage 개인정보 가이드 추가
- 외부 스크립트 도입 정책 추가
- 전역 404/error 페이지와 공통 오류/빈 상태 컴포넌트 추가

## 6. 배포 전 사람이 확인해야 할 항목

- `NEXT_PUBLIC_SITE_URL` 실제 도메인 설정
- `.env` 파일 미커밋 여부
- 외부 광고/분석/제휴 스크립트 미삽입 상태
- 투자 유의사항 문구
- ETF 데이터 기준일과 정적 데이터 안내
- 모바일 화면에서 오류/빈 상태 UI

## 7. 향후 보안 개선 후보

- 개인정보 처리방침 문서 작성
- 쿠키/분석 동의 정책 검토
- 외부 API 도입 시 서버 전용 key 관리
- 오류 로깅 도입 시 개인정보 마스킹 정책 추가
