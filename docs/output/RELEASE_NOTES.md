# 릴리즈 노트

## 1. 버전

v0.1.0 MVP

## 2. 주요 기능

- 배당금 계산
- ETF 상세 정보
- 관심종목
- ETF 비교
- ETF 랭킹
- 배당 재투자 시뮬레이션
- 배당락/실적 캘린더
- 가격/배당 알림 규칙 저장
- 포트폴리오 저장
- 포트폴리오 배당 캘린더
- 데이터 백업/복원
- 가이드 콘텐츠
- 오류/404/빈 상태 안내

## 3. 개선 사항

- SEO 메타데이터
- sitemap/robots
- UI/UX 공통 컴포넌트
- 데이터 최신성 안내
- 수익화 placeholder
- 성능/접근성/SEO 점검 문서
- 회귀 테스트 계획 문서
- 보안/개인정보 점검 문서
- localStorage 개인정보 가이드
- 외부 스크립트 도입 정책
- 수동 CSV 데이터 검증 구조
- v0.1.0 배포 패키징 문서

- `npm run lint`: 통과

- `npm run build`: 통과

## 5. 주의사항

- 정적 데이터 기반 MVP이다.
- 실시간 주가와 실제 배당 캘린더 API는 연동하지 않았다.
- 투자 추천 서비스가 아니다.
- 관심종목, 알림 규칙, 포트폴리오는 localStorage 기반으로 저장된다.
- 실제 광고, GA4/GTM, 제휴 스크립트는 삽입하지 않았다.
