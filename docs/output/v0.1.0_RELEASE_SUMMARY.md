# v0.1.0 릴리즈 요약

## 1. 릴리즈 개요

- 프로젝트명: Dividend Lab Korea
- 버전: v0.1.0
- 목적: 한국 투자자를 위한 미국 배당 ETF 계산/비교/관리 MVP

## 2. 포함 기능

- 배당금 계산기
- ETF 상세 페이지
- 관심종목 워치리스트
- ETF 비교
- ETF 랭킹/스크리너
- 배당 재투자 시뮬레이션
- 배당락/실적 캘린더
- 알림 규칙 저장
- 포트폴리오 저장
- 포트폴리오 배당 캘린더
- 데이터 백업/복원
- 가이드 콘텐츠
- SEO metadata
- sitemap/robots
- 수익화 placeholder
- 데이터 최신성 안내
- 운영/보안/배포 문서

## 3. 제외 기능

- 실시간 주가 API
- 실시간 배당 데이터 API
- 로그인
- DB 저장
- 서버 알림
- 이메일 알림
- 결제
- 실제 광고 스크립트
- 실제 제휴 링크
- AI 종목 분석
- 증권사 연동

## 4. 기술적 특징

- Next.js App Router
- TypeScript
- Tailwind CSS
- 정적 ETF 데이터
- localStorage 기반 사용자 데이터
- 테스트 가능한 도메인 로직
- SEO 페이지 구조

## 5. 데이터 주의사항

- ETF 데이터는 정적 데이터다.
- 배당률, 운용보수, 캘린더는 최신이 아닐 수 있다.
- 실제 투자 전 운용사 공식 자료와 최신 공시 확인이 필요하다.

## 6. 투자 유의사항

- 계산 결과는 참고용이다.
- 투자 추천이 아니다.
- 투자 판단 책임은 사용자 본인에게 있다.
