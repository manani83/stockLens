# 알려진 제한사항

## 1. 데이터 제한

- ETF 데이터는 정적 데이터이다.
- 배당률과 운용보수는 최신이 아닐 수 있다.
- 캘린더 일정은 예시 데이터일 수 있다.

## 2. 기능 제한

- 실시간 주가가 없다.
- 로그인이 없다.
- DB 저장이 없다.
- 서버 알림이 없다.
- 증권사 연동이 없다.
- 실제 광고/제휴 링크가 없다.
- 실제 GA4/GTM 스크립트가 없다.
- 외부 오류 로깅 서비스가 없다.

## 3. 저장 방식 제한

- 관심종목, 알림, 포트폴리오는 localStorage에 저장된다.
- 브라우저 데이터 삭제 시 정보가 손실될 수 있다.
- 기기 간 동기화가 없다.
- 백업 JSON 파일 관리는 사용자 책임이다.

## 4. 투자 정보 제한

- 계산 결과는 참고용이다.
- 투자 추천이 아니다.
- 실제 투자 전 운용사 공식 자료와 최신 공시 확인이 필요하다.

## 5. 배포 전 제한

- 실제 도메인과 `NEXT_PUBLIC_SITE_URL`은 배포자가 설정해야 한다.
- 모바일 화면은 실제 기기에서 최종 확인해야 한다.
- ETF 데이터 최신성은 사람이 공식 자료로 확인해야 한다.
