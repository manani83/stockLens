# 보안/개인정보 체크리스트

## 1. 목적

실서비스 배포 전 개인정보, localStorage, 환경변수, 외부 스크립트, 투자정보 고지 측면의 위험을 점검한다. 현재 MVP는 로그인, DB, 서버 저장, 외부 API, 실제 광고/분석 스크립트를 사용하지 않는다.

## 2. 환경변수 체크리스트

- [ ] `NEXT_PUBLIC_SITE_URL`은 공개되어도 되는 사이트 URL만 담는다.
- [ ] `NEXT_PUBLIC_ANALYTICS_PROVIDER`는 provider 선택값만 담는다.
- [ ] API KEY를 클라이언트 코드나 `NEXT_PUBLIC_*` 환경변수에 넣지 않는다.
- [ ] 향후 금융 API KEY는 서버 환경변수로만 관리한다.
- [ ] `.env` 파일을 저장소에 커밋하지 않는다.

## 3. localStorage 체크리스트

- [ ] `dividend-lab-watchlist` 저장 구조 확인
- [ ] `dividend-lab-alert-rules` 저장 구조 확인
- [ ] `dividend-lab-portfolio` 저장 구조 확인
- [ ] 이름, 이메일, 전화번호, 주소, 주민등록번호, 계좌번호를 저장하지 않는다.
- [ ] memo는 브라우저 안에만 저장하고 분석 이벤트나 외부 서비스로 전송하지 않는다.
- [ ] 백업/복원은 서버 업로드 없이 브라우저 파일 처리로만 동작한다.

## 4. 사용자 입력 체크리스트

- [ ] memo 입력값을 HTML로 직접 렌더링하지 않는다.
- [ ] `dangerouslySetInnerHTML`을 사용하지 않는다.
- [ ] 사용자 입력을 metadata나 HTML에 무분별하게 넣지 않는다.
- [ ] 백업 import JSON은 `validateBackupData`로 검증한다.
- [ ] 폼 오류는 사용자에게 필요한 수준의 안내만 표시한다.

## 5. 외부 스크립트 체크리스트

- [ ] 실제 광고 스크립트 미삽입
- [ ] 실제 GA4/GTM 스크립트 미삽입
- [ ] 실제 제휴 스크립트 미삽입
- [ ] 외부 스크립트 추가 전 약관, 개인정보 전송 범위, 쿠키 사용 여부 확인
- [ ] 스크립트 추가 결정은 `docs/output/decision-log.md`에 기록

## 6. 투자정보 고지 체크리스트

- [ ] 계산 결과는 참고용이라는 문구 표시
- [ ] ETF 데이터는 정적 데이터라는 문구 표시
- [ ] 투자 판단 책임은 사용자 본인에게 있다는 문구 표시
- [ ] 수익 보장, 원금 보장, 확정 수익 표현 없음
- [ ] 특정 ETF 매수/매도 권유 표현 없음

## 7. 배포 전 필수 확인

- [ ] `npm test`
- [ ] `npm run lint`
- [ ] `npm run typecheck`
- [ ] `npm run build`
- [ ] 주요 URL 수동 확인
- [ ] 404/error 페이지 확인
- [ ] localStorage 삭제/백업/복원 흐름 확인

## 8. 향후 API/DB 도입 시 추가 점검

- 인증/인가 설계
- 서버 로그 개인정보 마스킹
- API KEY 서버 환경변수 관리
- DB 암호화와 접근 권한
- 개인정보 처리방침
- 쿠키/분석 동의 정책
- 데이터 삭제 요청 처리
