# 콘텐츠 작성 가이드

## 1. 글 작성 톤

- 초보 투자자도 이해할 수 있는 설명형 문장을 사용한다.
- 투자 결정을 대신해주는 표현은 피한다.
- 계산과 비교 방법을 안내하는 교육용 톤을 유지한다.

## 2. 문단 구조

- 한 문단은 2~4문장으로 유지한다.
- 핵심 개념, 계산 방식, 주의사항, 관련 도구 순서로 구성한다.
- 너무 긴 문단은 나누어 읽기 쉽게 만든다.

## 3. 제목 작성 규칙

- 사용자가 검색할 법한 키워드를 포함한다.
- 과장된 제목을 피한다.
- “쉽게 보기”, “기본”, “주의할 점”처럼 정보성 표현을 사용한다.

## 4. 투자 유의사항 문구

본 콘텐츠는 교육용 참고 자료이며 특정 ETF의 매수 또는 매도를 권유하지 않습니다. 실제 투자 전 운용사 공식 자료와 최신 공시를 확인하세요.

## 5. 사용하면 안 되는 표현

- 무조건 추천
- 확정 수익
- 원금 보장
- 반드시 매수
- 안정적으로 돈 버는 방법
- 손실 없는 투자

## 6. 내부 링크 넣는 방법

- 계산 설명에는 `/` 배당금 계산기 링크를 연결한다.
- ETF 비교 설명에는 `/compare` 링크를 연결한다.
- 장기 결과 설명에는 `/simulation` 링크를 연결한다.
- 리스크 설명에는 `/rankings`와 관련 가이드 링크를 연결한다.

## 7. ETF 데이터 최신성 주의사항

- 정적 데이터 기준일을 확인한다.
- 공식 운용사 자료와 최신 공시 확인을 안내한다.
- 배당률, 운용보수, 분배금 정책은 변동될 수 있음을 명시한다.
