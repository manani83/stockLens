# SEO 색인 준비 가이드

## 사이트맵 확인 방법

- `/sitemap.xml`에 접속한다.
- 메인, ETF 상세, 비교, 랭킹, 시뮬레이션 URL이 포함되어 있는지 확인한다.

## robots.txt 확인 방법

- `/robots.txt`에 접속한다.
- `User-agent: *`, `Allow: /`, `Sitemap` URL이 표시되는지 확인한다.

## 배포 후 할 일

- 실제 도메인을 설정한다.
- `NEXT_PUBLIC_SITE_URL`을 실제 도메인으로 설정한다.
- Google Search Console에 사이트를 등록한다.
- sitemap을 제출한다.
- 주요 페이지 색인을 요청한다.

## 색인 대상 주요 페이지

- 메인
- ETF 상세 페이지
- 비교 페이지
- 랭킹 페이지
- 시뮬레이션 페이지

## 색인 제외 또는 주의 페이지

- 아직 없음
- 향후 로그인, 마이페이지, 관리자 페이지가 생기면 색인 제외가 필요하다.

## SEO 주의사항

- 투자 추천처럼 보이는 문구를 사용하지 않는다.
- 계산 결과는 참고용으로 명시한다.
- ETF 데이터의 최신성 검증이 필요하다.
- 배당률 데이터 업데이트 정책이 필요하다.
