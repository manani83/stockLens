# 요구사항

## MVP 필수 기능

- ETF/주식 선택
- 투자금 입력
- 환율 입력
- 배당률 입력
- 미국 배당세 15% 반영
- 세전/세후 연 배당금 계산
- 세전/세후 월 배당금 계산
- SCHD, JEPI, JEPQ, QQQI, QYLD 기본 데이터 제공
- ETF 상세 정보 페이지 구조 설계
- 관심종목 워치리스트 구조 설계
- ETF 비교 기능
- ETF 랭킹/스크리너 기능
- 배당락/실적 캘린더 확장 고려
- 알림 기능 확장 고려

## 초기 MVP에서 실제 구현할 기능

- 배당금 계산기
- ETF 기본 데이터
- ETF 상세 페이지 기본 구조
- 관심종목 localStorage 저장 구조
- ETF 비교 페이지
- ETF 랭킹/스크리너 페이지

## 초기 MVP 제외 기능

- 회원가입
- 로그인
- DB 저장
- 실시간 주가 API 연동
- 결제
- 관리자 페이지
- AI 뉴스 요약
- 증권사 연동
- 실제 푸시 알림
- 실시간 차트

## 2차 MVP 후보
