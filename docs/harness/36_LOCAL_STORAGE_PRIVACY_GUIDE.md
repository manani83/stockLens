# localStorage 개인정보 가이드

## 1. 사용 목적

로그인과 서버 저장 없이 사용자가 브라우저에서 관심 ETF, 알림 규칙, 포트폴리오 입력값을 보관할 수 있게 한다.

## 2. 저장 key 목록

| key | 용도 |
|---|---|
| `dividend-lab-watchlist` | 관심종목 ticker와 선택 memo |
| `dividend-lab-alert-rules` | 목표 가격/배당률/일정 알림 조건과 memo |
| `dividend-lab-portfolio` | 보유 ETF, 투자금, 수량, 평균단가, memo |

## 3. 저장 데이터 항목

- ticker
- 투자금
- 수량
- 평균단가
- 알림 유형
- 목표값
- 일정 기준일 전 알림 일수
- 사용자가 입력한 memo

## 4. 저장하지 않는 데이터

- 이름
- 이메일
- 전화번호
- 주민등록번호
- 계좌번호
- 주소
- 증권사 로그인 정보
- API KEY
- 결제 정보

## 5. 데이터 삭제 방법

- 브라우저 사이트 데이터 삭제
- 앱 내 삭제/clear 기능 사용
- 백업/복원 기능에서 Replace 모드 사용 시 기존 데이터 덮어쓰기 가능

## 6. 백업/복원 주의사항

- 백업 JSON 파일은 사용자의 기기에 저장된다.
- 백업 파일에는 localStorage 데이터가 포함될 수 있으므로 공용 PC나 공유 폴더에 보관하지 않는다.
- 가져오기 전 JSON 구조를 검증하지만 파일 내용의 최신성은 사용자가 확인해야 한다.

## 7. 한계

- 기기 간 동기화가 없다.
- 브라우저 데이터 삭제 시 데이터가 손실된다.
- 공용 PC에서는 다른 사용자가 같은 브라우저 프로필의 데이터를 볼 수 있다.
- 서버 저장이 아니므로 운영자가 복구할 수 없다.
