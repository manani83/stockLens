# 도메인 규칙

## 배당 계산 규칙

- 원화 투자금 / 환율 = 달러 투자금
- 달러 투자금 * 배당률 = 세전 연 배당금
- 세전 연 배당금 * (1 - 세율) = 세후 연 배당금
- 세전 연 배당금 / 12 = 세전 월 배당금
- 세후 연 배당금 / 12 = 세후 월 배당금
- 달러 금액 * 환율 = 원화 금액

배당률과 세율은 입력 시 percent 단위로 받고, 내부 계산 시 decimal 값으로 변환한다.

## ETF 데이터 규칙

- 티커는 대문자로 관리한다.
- 배당률은 percent 단위로 입력한다.
- 내부 계산 시 percent 값을 decimal로 변환한다.
- 배당주기는 Monthly, Quarterly, SemiAnnual, Annual, Unknown 중 하나로 관리한다.
- 초기 ETF 데이터는 정적 데이터로 관리한다.
- 데이터 값은 초기값이며 추후 검증 가능하도록 주석을 남긴다.

## 관심종목 규칙

- 초기 MVP에서는 로그인 없이 localStorage에 저장한다.
- 관심종목은 ticker 기준으로 중복 저장하지 않는다.
- 관심종목 삭제가 가능해야 한다.
- 관심종목 데이터는 ETF 기본 데이터와 연결해서 표시한다.

## ETF 상세 페이지 규칙

- 티커 기반 동적 라우팅을 고려한다.
- 존재하지 않는 티커는 Not Found 또는 안내 메시지를 표시한다.
- 상세 페이지에서 배당금 계산기로 연결할 수 있어야 한다.
