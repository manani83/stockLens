# 콘텐츠 운영 플로우

## 1. 콘텐츠 운영 목적

- 검색 유입을 확대한다.
- 사용자의 배당 투자 개념 이해를 돕는다.
- 계산기, 비교, 랭킹 페이지로 내부 링크를 연결한다.
- 투자 추천이 아닌 교육형 콘텐츠를 제공한다.

## 2. 콘텐츠 작성 절차

1. 키워드를 선정한다.
2. 검색 의도에 맞는 제목을 작성한다.
3. meta description에 사용할 설명을 작성한다.
4. 본문을 작성한다.
5. 투자 유의사항을 추가한다.
6. 관련 도구 내부 링크를 추가한다.
7. 관련 가이드를 `relatedSlugs`로 연결한다.
8. `npm run build`로 정적 페이지 생성을 확인한다.
9. `/sitemap.xml` 포함 여부를 확인한다.

## 3. 콘텐츠 추가 위치

- 데이터: `src/data/guideArticles.ts`
- 조회 로직: `src/domain/content/contentRepository.ts`
- 목록 페이지: `/guides`
- 상세 페이지: `/guides/[slug]`

## 4. 콘텐츠 작성 체크리스트

- [ ] 투자 추천 표현 없음
- [ ] 수익 보장 표현 없음
- [ ] 특정 ETF 매수/매도 권유 없음
- [ ] 계산기 또는 비교 페이지 내부 링크 포함
- [ ] 데이터 기준일 또는 참고용 문구 포함
- [ ] title/description 작성
- [ ] relatedSlugs 작성

## 5. 콘텐츠 주제 후보

- 월 100만원 배당 받으려면
- SCHD 장기투자 계산
- JEPI 월배당 구조
- JEPQ와 QYLD 차이
- 커버드콜 ETF 주의사항
- 미국 배당세 기본
- 환율이 배당금에 미치는 영향
- 배당 재투자 효과
