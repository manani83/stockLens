# 외부 데이터 제공자 검토

## 1. 검토 기준

- 주가 데이터 제공 여부
- ETF 배당 데이터 제공 여부
- 분배금 이력 제공 여부
- API 호출 제한
- 상업적 사용 가능 여부
- 비용
- 데이터 지연
- 한국 사용자에게 필요한 환율 데이터 제공 여부

## 2. 후보 카테고리

- 무료 금융 API
- 유료 금융 데이터 API
- ETF 운용사 공식 데이터
- 거래소 데이터
- 수동 CSV 관리

## 3. 최종 선택 전 확인할 것

- 약관
- 상업적 사용 가능 여부
- 재배포 가능 여부
- 호출 제한
- 장애 대응
- 데이터 기준일

## 4. 현재 결정

- MVP에서는 외부 API를 연동하지 않는다.
- API KEY를 추가하지 않는다.
- 네트워크 호출 코드를 작성하지 않는다.
- 데이터 값은 대규모로 변경하지 않는다.
