# 데이터 라이선스 리스크 체크리스트

## 1. 체크리스트

- [ ] 상업적 사용 가능 여부 확인
- [ ] 데이터 재배포 가능 여부 확인
- [ ] 캐싱 가능 여부 확인
- [ ] 화면 표시 가능 여부 확인
- [ ] API 응답 원문 저장 가능 여부 확인
- [ ] 호출 제한 확인
- [ ] 무료 플랜의 서비스 사용 가능 범위 확인
- [ ] 출처 표기 필요 여부 확인
- [ ] 약관 변경 대응 방식 확인
- [ ] 유료 전환 조건 확인

## 2. 사용하면 안 되는 데이터 운영 방식

- 약관 확인 없이 크롤링
- 출처 미표기 데이터 재배포
- 무료 API를 상업 서비스 핵심 기능으로 무제한 사용
- 라이선스가 불명확한 데이터를 광고 수익 페이지에 사용
- 사용자에게 최신 데이터처럼 표시하면서 실제로는 오래된 데이터 사용

## 3. 안전한 데이터 운영 방식

- 데이터 기준일 표시
- 데이터 출처 표시
- 참고용 문구 표시
- 공식 자료 확인 안내
- 데이터 오류 신고 경로 마련
- 자동 업데이트 전 수동 검증
- 약관 확인 날짜와 변경 이력 기록

## 4. 도입 보류 기준

- 상업적 사용 가능 여부가 확인되지 않았다.
- 캐싱 또는 화면 표시 허용 범위가 불명확하다.
- 배당 데이터의 기준일과 산출 방식이 불명확하다.
- 장애 시 정적 데이터 fallback을 제공할 수 없다.
