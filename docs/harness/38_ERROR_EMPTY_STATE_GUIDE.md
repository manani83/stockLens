# 오류/404/빈 상태 가이드

## 1. 오류 처리 원칙

- 사용자가 다음 행동을 선택할 수 있게 링크나 버튼을 제공한다.
- stack trace, digest, 내부 파일 경로를 노출하지 않는다.
- 오류 원인을 단정하지 않고 재시도 또는 주요 페이지 이동을 안내한다.

## 2. 404 페이지 원칙

- 주소 오류 또는 페이지 이동 가능성을 설명한다.
- 메인, 배당금 계산기, ETF 랭킹 같은 주요 진입점을 제공한다.
- 존재하지 않는 ticker, compare pair, guide slug는 각각 맥락에 맞는 안내를 제공한다.

## 3. 빈 상태 UI 원칙

- 비어 있는 이유를 짧게 설명한다.
- 사용자가 할 수 있는 다음 행동을 제시한다.
- 관심종목, 알림, 포트폴리오, 캘린더, 관련 가이드 없음 상태는 같은 톤으로 표시한다.

## 4. 폼 오류 메시지 원칙

- 오류 메시지는 `role="alert"`로 표시한다.
- 입력값을 그대로 HTML로 렌더링하지 않는다.
- 숫자 범위, 필수값, 잘못된 JSON 같은 사용자가 수정 가능한 내용을 안내한다.

## 5. 보여주면 안 되는 오류 정보

- stack trace
- 서버 파일 경로
- 환경변수 값
- API KEY
- localStorage 원문 전체
- 백업 JSON 원문 전체

## 6. 페이지별 오류 처리 기준

| 페이지 | 기준 |
|---|---|
| `/not-found` | 전역 404 안내와 주요 링크 제공 |
| `/error` | 다시 시도와 메인 이동 제공, 상세 오류 미노출 |
| `/etf/[ticker]` | 존재하지 않는 ticker 안내, 랭킹/메인 링크 제공 |
| `/compare/[pair]` | 잘못된 형식, 없는 ticker, 동일 ticker 비교 안내 |
| `/guides/[slug]` | 없는 slug 안내, 가이드 목록 링크 제공 |
| `/calendar` | 필터 결과 없음 안내 |
| `/alerts` | 저장된 알림 규칙 없음 안내 |
| `/portfolio` | 저장된 보유 ETF 없음 안내 |
| `/settings/backup` | 잘못된 JSON 파일 안내 |

## 7. 테스트 체크리스트

- [ ] 존재하지 않는 URL 확인
- [ ] 존재하지 않는 ETF URL 확인

- [ ] 존재하지 않는 guide URL 확인

- [ ] 빈 알림 규칙 상태 확인
- [ ] 빈 포트폴리오 상태 확인
- [ ] 잘못된 배당 계산 입력 확인
- [ ] 잘못된 백업 JSON 확인
