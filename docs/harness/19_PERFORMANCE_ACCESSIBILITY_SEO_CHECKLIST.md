# 성능/접근성/SEO 최종 점검 체크리스트

## 1. 성능 체크리스트

- [x] localStorage, `useState`, `useEffect`, router 이동이 필요한 컴포넌트만 `"use client"`를 사용한다.
- [x] 정적 안내, 카드, 테이블, 문서성 컴포넌트는 서버 컴포넌트로 유지한다.
- [x] 캘린더, 차트, 아이콘 등 무거운 신규 라이브러리를 추가하지 않았다.
- [x] ETF/캘린더 데이터는 정적 데이터 import 기반으로 유지한다.
- [x] 빌드 결과에서 모든 주요 라우트가 생성되는지 확인한다.

## 2. 접근성 체크리스트

- [x] 주요 페이지는 h1을 하나씩 사용한다.
- [x] 주요 섹션은 h2, 반복 항목 제목은 h3 중심으로 구성한다.
- [x] 폼 input/select에는 label을 둔다.
- [x] 버튼은 동작, 링크는 페이지 이동에 사용한다.
- [x] 삭제 버튼에는 대상이 드러나는 텍스트 또는 `aria-label`을 둔다.
- [x] 모호한 “상세 보기” 링크는 ticker를 포함하도록 수정했다.
- [x] 오류/주의/상태 정보는 색상뿐 아니라 텍스트로 표시한다.

## 3. SEO 체크리스트

- [x] 메인 페이지 metadata가 있다.
- [x] ETF 상세 페이지는 `generateMetadata`를 사용한다.
- [x] 비교 페이지와 비교 상세 페이지 metadata가 있다.
- [x] 랭킹, 시뮬레이션, 캘린더, 알림, 포트폴리오, 백업 페이지 metadata가 있다.
- [x] 주요 페이지가 `InternalLinkSection`에 포함되어 있다.
- [x] `sitemap.ts`에 주요 정적 페이지, ETF 상세, 대표 비교 URL이 포함되어 있다.
- [x] `robots.ts`가 sitemap URL을 제공한다.
- [x] 투자 추천처럼 보이는 title/description 표현을 사용하지 않는다.

## 4. 모바일 UI 체크리스트

- [x] 랭킹과 캘린더는 모바일 카드형 UI를 우선한다.
- [x] 데스크톱 테이블은 `overflow-x-auto` 또는 최소 폭으로 가로 스크롤을 허용한다.
- [x] 폼 입력은 충분한 높이와 전체 폭을 사용한다.
- [x] CTA 버튼은 모바일에서 줄바꿈되어도 의미가 유지된다.
- [x] 고지 문구는 별도 박스로 콘텐츠와 구분된다.

## 5. 투자 정보 표현 체크리스트

- [x] “참고용”, “계산해볼 수 있습니다”, “비교해볼 수 있습니다” 표현을 사용한다.
- [x] “무조건 추천”, “확정 수익”, “원금 보장”, “반드시 매수” 같은 투자 권유 표현을 사용자 화면에 사용하지 않는다.
- [x] 계산 결과와 정적 데이터의 한계를 안내한다.
- [x] 공식 자료 확인 필요 문구를 유지한다.

## 6. 수정한 항목

- ETF 카드, 관심종목 카드, 랭킹 카드/테이블의 “상세 보기” 링크를 ticker 포함 텍스트로 수정했다.
- `src/lib/seo.test.ts`, `src/lib/siteUrl.test.ts`를 추가해 SEO helper와 사이트 URL 처리를 회귀 테스트에 포함했다.
- watchlist SSR 방어 테스트를 추가했다.

## 7. 남은 개선 후보

- 실제 브라우저 기반 Lighthouse 또는 axe 점검.
- 모바일 실기기에서 긴 ETF 이름, 긴 메모, 백업 파일명 표시 확인.
- 배포 도메인 설정 후 sitemap/robots 실제 URL 재확인.
- 공통 UI 컴포넌트 적용 범위 확대.
