# ETF 데이터 운영 플로우

## 1. ETF 데이터 운영 목적

- 계산기 정확성을 유지한다.
- ETF 비교 신뢰성을 확보한다.
- 랭킹/스크리너 품질을 유지한다.
- 사용자에게 데이터 기준일을 제공한다.

## 2. ETF 데이터 업데이트 절차

1. 운용사 공식 자료를 확인한다.
2. 배당률 또는 분배율을 확인한다.
3. 운용보수를 확인한다.
4. 분배금 지급 주기를 확인한다.
5. 위험도와 설명 문구를 검토한다.
6. `dataAsOf`를 갱신한다.
7. CSV 템플릿을 업데이트한다.
8. CSV parser 테스트를 실행한다.
9. `src/data/etfData.ts`에 사람이 반영한다.
10. `npm test`를 실행한다.
11. `npm run build`를 실행한다.
12. 변경사항을 `docs/output/decision-log.md`에 기록한다.

## 3. 데이터 검증 체크리스트

- [ ] ticker 정확성 확인
- [ ] name 정확성 확인
- [ ] issuer 정확성 확인
- [ ] dividendYieldPercent 확인
- [ ] expenseRatioPercent 확인
- [ ] payoutCycle 확인
- [ ] dataAsOf 갱신
- [ ] dataNote 유지
- [ ] 투자 유의사항 유지

## 4. 데이터 오류 대응

1. 오류를 발견한다.
2. 영향 페이지를 확인한다.
3. ETF 데이터를 수정한다.
4. 테스트를 실행한다.
5. 변경 로그를 기록한다.
6. 필요 시 사용자 안내 문구를 보강한다.

## 5. 업데이트 주기

- 초기: 월 1회 수동 점검
- 트래픽 증가 후: 주 1회 점검 검토
- 실데이터 연동 후: 자동 업데이트 + 수동 검증
