# 외부 스크립트 도입 정책

## 1. 도입 원칙

- 사용 목적이 명확한 스크립트만 추가한다.
- 개인정보, memo, 백업 원문, localStorage 원문을 외부로 전송하지 않는다.
- 스크립트 도입 전 약관, 쿠키 사용, 개인정보 처리 범위, 성능 영향을 확인한다.
- 실제 삽입 전 `docs/output/decision-log.md`에 결정 사유를 기록한다.

## 2. 광고 스크립트 도입 전 확인사항

- 광고 네트워크 약관
- 쿠키와 추적 범위
- 광고 위치가 계산기 입력과 결과를 방해하지 않는지
- 투자정보 페이지에서 광고 고지 문구가 필요한지
- 민감한 투자 입력값이 광고 네트워크로 전달되지 않는지

## 3. 분석도구 스크립트 도입 전 확인사항

- GA4/GTM 또는 다른 provider의 데이터 수집 범위
- 이벤트 payload에 memo, 백업 데이터, localStorage 원문 미포함
- IP/쿠키/디바이스 식별자 처리 방식
- 사용자 동의가 필요한지 여부
- 내부 테스트와 운영 환경 분리

## 4. 제휴 스크립트 도입 전 확인사항

- 제휴 링크/스크립트 약관
- 제휴 고지 문구 표시
- 특정 증권사 또는 ETF 추천처럼 보이지 않는지
- 클릭 추적 데이터 범위
- 사용자 입력값 전송 여부

## 5. 개인정보 전송 금지 원칙

- 이름, 이메일, 전화번호, 주소, 계좌번호, 증권사 로그인 정보를 수집하거나 전송하지 않는다.
- memo와 백업 JSON은 외부 분석/광고/제휴 스크립트에 전달하지 않는다.

## 6. 사용자 입력값 전송 금지 원칙

- 투자금, 수량, 평균단가, memo 같은 입력값은 외부 스크립트 payload에 포함하지 않는다.
- 분석 이벤트는 page, ticker, category 같은 최소 수준으로 제한한다.

## 7. decision-log 기록 규칙

외부 스크립트를 추가할 때는 다음 항목을 기록한다.

- provider 이름
- 도입 목적
- 수집 이벤트와 payload
- 약관 확인 날짜
- 개인정보 전송 여부
- 비활성화 또는 제거 방법
