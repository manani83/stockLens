# 포트폴리오 localStorage MVP 설계

## 1. 현재 범위

- 보유 ETF, 수량, 평균단가, 투자금, 메모를 브라우저 `localStorage`에 저장한다.
- 로그인, DB 저장, 서버 저장, 증권사 연동은 제공하지 않는다.
- 실시간 주가 API를 사용하지 않고 정적 ETF 데이터의 배당률을 사용한다.

## 2. 입력 방식

- 사용자는 투자금 원화를 직접 입력할 수 있다.
- 또는 수량과 평균단가 달러를 입력할 수 있다.
- 투자금 원화와 수량/평균단가가 모두 있으면 투자금 원화를 우선 사용한다.

## 3. 계산 방식

- ETF 기본 데이터의 `dividendYieldPercent`를 사용한다.
- 투자금 기준 예상 세전 연 배당금을 계산한다.
- 세율을 반영해 세후 연 배당금과 세후 월 배당금을 계산한다.
- 기본 환율과 세율은 MVP 화면에서 고정값으로 사용한다.

## 4. 향후 확장 방향

- 사용자 계정 기반 서버 저장
- 실시간 또는 지연 가격 데이터 연동
- 매수/매도 이력 관리
- 환율 설정 저장
- 포트폴리오 비중, 섹터, 배당 캘린더 연동

## 5. 주의사항

- 계산 결과는 단순 참고용이다.
- 실제 수익률, 배당금, 환율, 세금은 달라질 수 있다.
- 브라우저 데이터 삭제 시 저장된 포트폴리오가 사라질 수 있다.
- 특정 ETF 매수 또는 매도를 권유하지 않는다.
