# 가격/배당 알림 규칙 설계

## 1. 현재 범위

- 알림 규칙은 브라우저 `localStorage`에 저장한다.
- 실제 푸시 알림, 이메일 알림, 서버 스케줄러는 제공하지 않는다.
- 실시간 가격 감지와 외부 주가 API 연동은 제공하지 않는다.
- 현재 기능은 사용자가 향후 알림 조건을 정의해볼 수 있는 MVP 초안이다.

## 2. 알림 유형

- 목표 가격 이하
- 목표 가격 이상
- 배당률 이상
- 배당락일 N일 전
- 배당 지급일 N일 전

## 3. 향후 확장 방향

- 실시간 가격 API 연동
- 이메일 알림
- 브라우저 푸시 알림
- 서버 스케줄러
- 사용자 계정 기반 알림 저장

## 4. 주의사항

- 알림은 투자 추천이 아니다.
- 데이터 지연 가능성이 있다.
- 실제 투자 전 공식 데이터 확인이 필요하다.
- 현재 저장 데이터는 브라우저 데이터 삭제 시 함께 사라질 수 있다.
