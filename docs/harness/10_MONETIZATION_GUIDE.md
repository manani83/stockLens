# 수익화 준비 가이드

## 1. 수익화 방향

- 광고: 주요 콘텐츠 흐름을 방해하지 않는 위치에 광고 영역을 둘 수 있다.
- 증권사 제휴: 향후 계좌개설, 환전, 수수료 정보를 비교하는 중립적 영역으로 확장할 수 있다.
- 데이터 서비스 제휴: ETF 데이터, 공시, 배당 캘린더 같은 데이터 서비스 연동을 검토할 수 있다.
- 프리미엄 계산기: 더 상세한 세금, 환율, 포트폴리오 계산 기능을 유료 기능 후보로 검토할 수 있다.
- 뉴스레터: 배당 ETF 업데이트, 데이터 변경 내역, 운영 공지를 전달하는 채널로 검토할 수 있다.

## 2. 초기에는 하지 말아야 할 것

- 실제 광고 스크립트를 삽입하지 않는다.
- 검증되지 않은 제휴 링크를 삽입하지 않는다.
- 투자 추천처럼 보이는 문구를 사용하지 않는다.
- 수익률 보장 표현을 사용하지 않는다.

## 3. 광고 배치 원칙

- 계산 결과를 가리지 않는다.
- 사용자의 입력 흐름을 방해하지 않는다.
- 광고와 콘텐츠를 명확히 구분한다.
- 모바일에서 과한 광고 영역을 피한다.

## 4. 제휴 고지 원칙

- 제휴 링크가 포함될 수 있음을 명확히 표시한다.
- 투자 판단 책임은 사용자에게 있음을 명시한다.
- 특정 상품을 객관적 근거 없이 추천하지 않는다.
